Proof of concept for Amazon Bedrock AgentCore, built with the Strands Agents SDK

Connecting

Ask a question about the sample Spring Boot service, or pick one of the examples above. Citations open the exact lines in the source file.

Guardrails

  • At most 8 tool calls per question, so the agent cannot loop or run up cost.
  • read_file refuses any path outside the repository.
  • Answers only from retrieved code, and says “Not found in the code.” instead of guessing.
  • Read only: the agent never changes code.

Measured, not assumed

  • An 11 question golden set, including one question the code cannot answer.
  • Retrieval scored with recall@3 and MRR; see the Evaluation tab.
  • Unit tests and CI that fail the build if recall drops below 90%.

Where it runs

  • This demo: a local web app on 127.0.0.1.
  • Production path: agent.py is an Amazon Bedrock AgentCore Runtime entrypoint, deployable with agentcore configure and agentcore launch.
